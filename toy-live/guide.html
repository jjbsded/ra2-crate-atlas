地图 / Maps · 概率演示 / Probability demo

选择「红色警戒 2」或「尤里的复仇」，再选择本机 .map／.yrm／.mpr 文件。文件只在浏览器内读取，后台线程执行解压、附近搜索和有限重抽的精确整数计算；不上传地图，不需要本地游戏目录。每个文件最大 16 MB。

Choose Red Alert 2 or Yuri’s Revenge, then select a local .map / .yrm / .mpr file, up to 16 MB. A browser worker decodes the map and computes nearby searches and exact finite-retry probabilities. Map files are not uploaded; no game directory is required.

官方地图沿用预计算和原版共享图集。自定义地图逐项复用包内原版素材，仅缺失的地形、朝向或损伤状态采用简绘；主图、小地图、区域裁图、3D 和导出共用当前布局。1× 为没有邻格转入的基准，来源百分比表示固定从该来源格开始的单次转移概率，不包含失败重抽。

Official maps retain precomputed results and original shared atlases. Custom maps reuse bundled original artwork, with simplified fallbacks only for missing terrain, directions or damage states in the main view, minimap, regions, 3D and exports. 1× is the no-incoming-transfer baseline; origin percentages describe one search from that fixed origin, excluding retries.

矿石／树木开关第一次切换时现场计算，然后缓存两种状态。计算中可取消，失败保留当前地图。区域按地图内容自动保存；刷新后需重新选择文件，区域会恢复。单指拖动平移、轻点选格、双指缩放；区域编辑可切换移动／画笔。图片可导出 PNG／JPEG，概率可导出 JSON／CSV。

Ore/Trees computes each layout on first use and caches both states. You can cancel a calculation; failures keep the current map. Regions are saved by map content. Reselect the file after reloading to restore them. Drag to pan, tap to select, pinch to zoom; region editing provides Pan/Brush touch modes. Export images as PNG/JPEG and probabilities as JSON/CSV.

支持范围：原版资源地图及简单内置规则覆盖；不运行触发、脚本、动态单位与矿石生长，或 Mod 扩展。未知对象按「选中后重抽」给出告警和近似概率，已知阻挡仍生效；缺失地形、未知覆盖物和不支持的基础逐项告警并近似处理；无法定位的记录被跳过。详情保留区块、索引／类型、坐标和数量。地图尺寸或核心地形区块损坏仍会停止，并显示文件、阶段和技术详情。近似结果不验证放箱后禁行风险。

Scope: stock-asset maps and simple embedded rule overrides. Triggers, scripts, moving units, ore growth and Mod extensions are not simulated. Unknown objects produce warnings and approximate retry-on-landing results while known blockers still apply. Missing terrain, unknown overlays and unsupported foundations produce item-level recovery warnings. Unlocatable records are skipped. Details include sections, indexes/types, positions and counts. Invalid dimensions or corrupt core terrain still stop analysis, with file, stage and technical details. Approximate results do not verify post-placement blocking risks.

推荐新版浏览器；需要 Worker、BigInt、Web Crypto、gzip 解压；3D 需要 WebGL。用 HTTPS 或 localhost 打开，不支持直接双击 HTML。手机内置浏览器下载行为可能不同，本地触控模拟不等于真机验收。

INI 重复键取值冲突时保留最后一条，并告警显示区块、键名、前后行号与取值；可能影响计算时标为近似，不代表已验证游戏的覆盖顺序。定义中的 Sight、RequiredHouses 不参与静态计算，只告警。相同重复值不告警；核心地形和尺寸仍需校验。

Conflicting INI keys retain their last occurrence with section, key, line numbers and values in the warning. Potentially relevant conflicts mark results approximate, without claiming verified engine precedence. Definition fields Sight and RequiredHouses are unused by the static model and only produce warnings. Equal duplicate values are accepted; core terrain and dimensions are still validated.

Use a current browser with Workers, BigInt, Web Crypto and gzip decompression; 3D needs WebGL. Serve over HTTPS or localhost, not file://. Embedded-browser downloads vary. Local touch emulation does not replace real-device testing.
