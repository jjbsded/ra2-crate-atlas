# Toy 接入载具光照修复：包体实测

日期：2026-11-03。光照实现：`ra2-vpl-diffuse-specular-v1`。接口和限制见 [光照复用说明](voxel-lighting.md)。

本文保留正式接入前的隔离测量记录。预烘焙方案现已接入正常构建器，实际成品大小、路径与构建命令见 [正式预烘焙构建](toy-lighting-release.md)；下表不是最终交付包的大小。

## 结论与大小口径

按项目现有的 **ZIP 不超过 50,000,000 字节**门槛，两个原版贴图 Toy 方案都能加入此次光照修复，增量较小。不需要减少地图、降低概率精度或改用有损图片。

| 网页包 | 基线 ZIP／字节 | 新光照 ZIP／字节 | 增量／字节 | 距 50 MB 余量／字节 |
| --- | ---: | ---: | ---: | ---: |
| 官方地图原版贴图版 | 49,614,427 | 49,621,557 | +7,130 | 378,443 |
| 现场计算实验版 | 48,678,378 | 48,813,558 | +135,180 | 1,186,442 |

十进制分别约为 **49.622 MB** 和 **48.814 MB**。官方地图版余量较紧，后续增加内容仍须执行 50 MB 构建门禁；本次结果不保证任意后续改动都能容纳。

这是压缩上传包的实测，**不等于解压大小小于 50 MB**。新候选解压后分别为 52,840,536 字节和 50,032,852 字节。如果目标平台按解压后大小限制，则这两个候选尚不满足该口径。本次没有验证平台实际上传规则或完成平台发布。

## 为什么增量小

Toy 显示构建时生成的图集，光照计算在开发机完成。浏览器仍读取最终 RGBA 图集或调色盘索引，不新增 Python、NumPy、原生 DLL、原始 MIX、VXL 或 HVA。修复改变的是现有像素及其压缩率，旧图集由新图集替换；没有额外叠加一套完整素材。

官方地图版只需处理固定布局中的体素部件，图集仍为 662 页无损 WebP。现场计算版还提供可放入自定义地图的单位及 32 向索引贴图，因此变化更多；其补充对象库仍为 67 页 PNG，库的未压缩文件大小从 5,820,521 字节变为 5,948,227 字节。

旧 `toy-official-3d`／v0.4 简绘包使用符号对象，原本不显示 VXL 光照。单独加入算法不会使这些符号产生新的受光效果；本次测量针对已有原版贴图的两个构建。

## 测量方法与验证

基线为 `output/toy-original.zip` 和最新的 `output/toy-live-ini-fix.zip`，不是较早的 `toy-live.zip`。先核对基线清单全部文件哈希，再解压到独立测量目录。保留原有 131 个菜单选项、147 个地图／版本组合和 294 套布局；分析数据不重算、不降精度。

278 套去重布局中有 112 套包含体素部件，已用新版完整版绘制器重新采集；其余布局复用已有数据。所有图集保持无损；旧页只有在完整解码像素及尺寸一致时才复用。现场计算版另外重建共享素材索引和全套补充对象库，更新浏览器素材版本。

已通过：

- 278 套布局的采集对比：地形、透明轮廓、绘制位置、阴影、3D 对象锚点保持一致，103 对唯一帧的颜色发生变化。
- 官方地图版 `verify-toy.py`：131 项、294 套布局的格子、精确概率、标记、禁行风险及来源搜索数据与原始分析缓存一致；全包清单、相对引用和 ZIP 哈希通过。
- 两个候选与各自基线逐文件核对：结果只改变图集引用；界面与分析代码不变，现场版额外更新素材版本。两份基线 ZIP 保持原样。
- 现场对象库 9 个游戏／气候范围、32,946 个状态、7,966 对唯一绘制组合：状态覆盖、调色盘、部件坐标和透明轮廓不变，其中 6,592 对组合颜色改变。
- 现有真实渲染器对照测试重定向至候选对象库，32 种代表状态的像素、所属色换色、朝向、锚点及损坏建筑检查通过。

## 测量发现及正式接入处理

上述隔离测量没有替换旧 Toy 构建。测量脚本的包仍带有 `artworkMeasurementOnly`，应使用后续正常构建器生成的正式成品。以下问题已在正式预烘焙流程中处理：

1. 命令记录表面不支持真实图像保存接口，现由 `render(..., save_images=False)` 明确跳过整图编码，绘制、遮挡及审计照常进行。
2. 两类烘焙缓存改用 `toy_build_inputs.artwork_fingerprint()`，包含光照、法线、绘制依赖、实际 worker／DLL 及经校验的原版资源身份。
3. 保留分析源码指纹门禁，从当前源码生成匹配的官方底包，再构建图集；没有篡改旧清单指纹来绕过检查。
4. 正式构建同步重建现场共享素材索引和对象库、更新 `liveVersion`、清理不再引用的页，并执行严格 50,000,000 字节门禁。只在完整解码像素一致时复用已有压缩页。

新光照仍是静止、直立模型的近似；地图环境色、局部灯光和动态法线等范围不因 Toy 接入而扩大。
