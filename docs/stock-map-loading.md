# 官方地图加载边界

本轮补齐原先剩余的 10 份官方地图文件。结论针对内置 RA2 1.006 / YR 1.001
资源与文件初始状态，不推进触发器、单位任务或矿石生长。源地图字节不改写。

## 普通斜坡上的矿石

涉及原版加州高速公路、大矿区抢地盘、心脏地带（作战／巨富）、紧要关头，
共 5 份文件。

原生 Overlay::Mark（YR `5FC570`，RA2 `5DA970`）允许坡型 0～4。
矿石邻接重算（YR `4818E0`，RA2 `476BA0`）调整密度帧，不因为这些普通坡面
删除矿石。YR `Scenario_Load 686B20` 在加载阶段增加 `IKnowWhatImDoing`；
OverlayPack 先创建覆盖物，OverlayDataPack 随后写入密度数据（`5FD2E0`）。
因此这些格子应保留矿石覆盖物，已有 Overlay 会令放箱重试。

`SlopeIndex > 4` 的预放矿石仍不属于精确加载模型，进入近似分析时会显示假设告警：Mark 会拒绝覆盖物，而工具尚未建模
整个后续加载阶段。不能简单把全部斜坡矿石放行。

同时修复 `TIB2_* → Image=TIBxx` 的渲染解析：气候后缀、调色盘等 art 属性
必须读取被引用图像的节。此前直接查 `TIB2_*`，会错找不存在的 `tibxx.shp`，
遗漏实际存在的 `tibxx.tem` 等素材。主地图、小地图、图片导出和 3D 共用该解析。

## 重返巴黎的边界桥梁

RA2 `mp33u4.map` 与 YR `xmp33u4.map` 的 `(18,71)` 是 BRIDGE1。
桥面格为 `(18,69)`～`(18,72)`，都在地图中；前方第三步 `(18,68)` 仅接收
`0x1000` 投影标志，没有 `0x100` 桥面标志。

原生桥初始化函数遇到这个不存在的格子时，把投影位写入地图外的占位 Cell，
不创建额外桥面，也不改变已存在桥面的占用。模型现在允许仅第三步投影越界；
真正的桥面格越界继续报错。

## 已登记、完全未定义的尤复建筑

- `c1a02md.map`：CALA02，`(107,118)`。
- `c3y03md.map`：CALOND02，`(141,75)`、`(106,136)`。

这些类型确实在 BuildingTypes 中登记，但内置 rules、art 及地图都没有对应
定义。不能按“未登记类型”跳过，也不能只因记录生命值为 0 就认为没有占用。

YR BuildingType 构造函数 `45DD90` 将 FoundationData（偏移 `0xDFC`）置空。
没有规则节时，ReadINI 链 `45FE50 → 712170 → 5F92D0 → 410A60` 返回失败，
不会进入读取基础定义的分支。`45EC20` 将空基础返回为仅含
`(32767,32767)` 结束标记的列表；原生地图登记函数 `5683C0` 因而不插入任何
格子的 Content。该结论不依赖记录生命值。

工具为这些对象记录空基础、无贴图状态，并将其写入
`metadata.emptyFoundationObjects` 和对象绘制审计。原始对象记录仍保留。
该例外仅适用于尤复、已在原版注册表登记、且地图／rules／art 均完全没有定义
的建筑；其他缺失定义保留告警并使用已说明的近似处理。

## 重复的 Sight

`c3y02md.map` 在 `[CAMEX01]` 写有 `Sight=6` 和 `Sight=7`。
视野范围不参与当前静态箱子概率、占用或贴图模型，因此允许分析，同时通过
`metadata.irrelevantDuplicateKeys` 保留节、行号和冲突值，并在界面中说明。
这不表示已经确认游戏选择哪个值。

普通严格 INI 解析仍拒绝冲突值；地图分析只为 Sight 提供这一例外。
Strength、基础、通行、箱子规则等其他冲突键和重复节继续拒绝。

## 验证与范围

- `verify-remaining-maps.py`：上述 10 份地图完整概率与渲染分析；
  无缺失覆盖物或建筑／单位贴图，原始对象保留，危险输入仍拒绝。
- `verify-map-loading-native.py`：两个版本各 3,840 个边界桥格对照、
  各 27 个矿石坡型／邻接用例；YR 空规则节返回链、两种生命值下的空基础，
  以及非空 1×1 基础的正向对照。
- `verify-realmap.py`：冰天雪地全部 39,601 个初始坐标、114 个独立分数概率
  分布及六种气候回归。
- `verify-official-maps.py`：248 份原地图 SHA-256、目录合并和选择校验。

原生测试在 Unicorn 隔离内存中执行固定哈希的原程序指令，未启动游戏、
未修改游戏文件。INI 查询、分配器、通用对象服务和重绘等夹具替代项在脚本
中逐项标明。该验证不是完整对局试玩，也不证明动态路径可达性。
程序指纹见 [桥梁研究](bridge-crates.md)。
