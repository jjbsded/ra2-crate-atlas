## 新增修复与产品整理

- 跨 DPI 且 CSS 尺寸不变时，旧版 1239×813 的画布在 DPR=2 仍是 1239×813；修复后变为对应物理像素尺寸。同页连续切换 1→2→1.25→1，视角保持相同。媒体查询未发事件的 Chromium 环境也覆盖。
- 唯一 Toy 的页面标题、说明、演示和错误范围文案去掉“现场版／实验版”标识，保留自定义地图分析能力。
- `build-toy.py` 与 `build-toy-original.py` 只生成内部数据／图集，不生成可分发 ZIP 或 CMD；`build-toy-live.py` 是唯一 Toy 最终组装步骤。内部路径及 legacy 格式标记保留以避免破坏兼容。对最终 Toy 直接执行共享前端刷新会被拒绝，防止意外丢失本地分析功能。
- 本轮仅改显示与产品发布流程，概率和绘图算法没有再次修改；直接复用已验证的无损图集，不重新烘焙或降低画质。

## 验收记录

当前完整证据写入 `output/review-verification-20261103/`。其中 `full-ui/ui.json` 来自实际完整版页面，覆盖四种初始 DPI、连续 DPI 变化、窗口／全屏、默认状态、真实 DOM 开关联动、像素放大和按钮命中。`full-building-tests.log` 是实际包内渲染模块的 162 组所属色测试。`portable.json` 检查包内运行环境、渲染版本 16、单位亮度 step=37、发布清单与 ZIP CRC。

上轮 `output/display-verification-20261103/pixel-parity.json` 的四张原生层与完整渲染逐像素相同（5580×2445、最大差值 0）；本轮沿用素材须通过文件 SHA-256 一致性验证。完整所有地图图集包含最长边 9600 的地图，没有 9000 上限缩小。缩小整张大地图时必然需要采样，游戏字体／动态局部光照也不在完全逐像素复刻范围内。

照明已修复明确遗漏的 VPL 和最终亮度阶段，但仍是静态近似，不承诺与游戏在所有环境下亮度完全相同；动态灯光、天气、部件倾斜、Mod 扩展等限制见接入文档。

## 后续：真实浏览器旧界面缓存修复

用户反馈由最新入口进入后仍看到两个禁行开关，Ctrl+F5 后恢复正常。服务返回的 HTML 已是新版，说明此前新浏览器测试没有覆盖已有浏览器缓存的升级路径。补充修复：每次启动唯一页面 URL；HTML／JS／CSS 禁止缓存并始终返回当前内容；HTML 内脚本／样式链接携带程序指纹，绕过旧缓存。地图图片缓存、分析结果和区域设置保留。详见 [便携版说明](../PORTABLE.md)；新增 `verify-server-cache.py` 覆盖旧条件请求、同时间戳升级、资源地址、图片缓存和复用现有服务再次启动。
