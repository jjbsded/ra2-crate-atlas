# 2026-11-03 光照后续与显示修复交付

绘图版本 16；光照完整接入文档：[voxel-lighting.md](voxel-lighting.md)。该文档包含之前新增的最终亮度阶段、本轮所属色修复，以及 Save2Map 的增量接入位置。另一个会话应以该文档为准；本次没有代替它修改 Save2Map 程序。

## 已完成的修改

- RA2/YR 不再因旧 `Remapable=no` 跳过单位调色盘的所属色索引 16–31。心灵控制塔底座、裂缝产生器、光棱塔、中立油井／机场的主体与附属动画一起换色；真实装饰色、透明轮廓不变。
- 默认关闭格线、占用标识。删除单独的潜在禁行开关，由“放箱后禁行格”同时控制当前和清空对象后的潜在风险。
- 在“显示 1× 标签”左侧加入“显示 1× 图层”。它单独控制精确 1× 填色，并受概率图层总开关控制；不改变概率、搜索或标签选项。
- 主画布、离屏地图缓存、导航缩略图按 CSS 尺寸和实际 DPR 绘制，覆盖窗口／全屏与 DPI 变化；像素图放大关闭平滑。超大地图不再预缩到最长边 9000 像素，所有底图使用原生尺寸、无损 PNG/WebP。Toy 同步使用原生无损图集。
- 小地图按钮的透明文本限定在按钮边界内，避免文字溢出扩大命中范围；保留无障碍名称。
- 最新完整版入口固定使用其内置 Python。Toy ZIP 增加 `Start Toy.cmd` 和仅依赖 Windows 自带 PowerShell 的本地静态服务，无需安装 Python。请先完整解压 ZIP；浏览器关闭后，关闭启动窗口即可停止对应服务。

屏幕底图与 Toy 图集没有有损压缩；缩小总览仍会采样，完整地图 JPEG 导出保持其原有 JPEG 格式。静态画面尚不等于游戏动态灯光、动画和阴影的完整复现。
